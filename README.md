Система состояний и травм (enum StatusEffect и struct Buff) 
Опишите структуру активного эффекта (тип эффекта через enum: Здоров, Растяжение, Отравление, Бодрость; оставшееся количество ходов действия). В походе при каждом шаге есть шанс 5% наступить на колючку или съесть странную ягоду, получив эффект на 10 шагов. «Растяжение» удваивает расход выносливости на шаг, «Отравление» отнимает по 2 HP за шаг, а «Бодрость» позволяет ходить бесплатно.
